You will now be taken to the system Accessibility settings.  

There, you need to enable the PenMouse S accessibility service for the app to function correctly.  
Accessibility services are needed to:
- Display the cursor overlay above other apps, including the notification panel and the lock screen
- Simulate touch input on the screen, mirroring S&nbsp;Pen movements

PenMouse S **does not** read, collect, store, or share any screen content or user data through the Accessibility Service.
