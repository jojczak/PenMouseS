# Point
#### Mode Overview

Point Mode is a simplified version of Mouse Mode, ideal for presentations or situations where you only need to click, not move the cursor.

## How it Works

This mode has one key difference from Mouse Mode:

* You **cannot** move the cursor using S Pen air gestures.
* To position the cursor, **touch and drag it with your finger** to the desired location on the screen.
* Once positioned, **press the S Pen button** to simulate a touch (a click) at that exact spot.

## Battery
Since Point Mode does not use the S Pen's gyroscope, it is **much more battery-efficient** than Mouse Mode.

### Customization
Remember to check the app's **Settings** to customize the cursor's appearance and behavior.
