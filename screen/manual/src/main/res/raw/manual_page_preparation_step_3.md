# Step 3
#### Accessibility service

Pen Mouse S requires its accessibility service to be enabled for proper functionality.

Accessibility services are needed to:
- Display the cursor above other apps, including the notification panel and the lock screen
- Simulate touch input on the screen, mirroring S&nbsp;Pen movements

**PenMouse S **does not** read, collect, store, or share any screen content or user data through the Accessibility Service.**
